Clean Frame Manager — Quick Guide

Use this checklist to install a launcher, choose the Home launcher, and safely return to Samsung Home.

  1. Enter the TV IP address and click Connect TV.
  2. If needed, open Developer Mode Setup Guide and complete the one-time TV pairing steps.
  3. Under Choose Launcher Version, select Original Clear Home or Google TV.
  4. Click Install Selected Launcher, then click Set Selected as Home.
  5. Use Check Home Assignment to confirm which launcher is active.

Testing and restoring

  • Launch Installed Launcher opens the installed launcher without changing the Home assignment.
  • Restore Samsung Launcher returns the TV to Samsung Home. This does not uninstall either Clean Frame launcher.
  • Reboot TV restarts the television. The manager connection will temporarily disconnect while the TV restarts.

Important: startup app after reboot

If the TV opens YouTube or another app after reboot, that app is saved as the TV startup app. Before rebooting, select the launcher you want and click Set Selected as Home. Then verify the assignment with Check Home Assignment.

Troubleshooting: TV detected but cannot connect

The manager may detect the TV through its REST API while Samsung Developer Mode/SDB is temporarily unavailable after a reboot. In that case, the TV is online, but remote actions cannot run yet.

  1. Open Apps on the TV and launch Developer Mode.
  2. Toggle Developer Mode off, then on again.
  3. Re-enter the computer’s IP address if the TV requests it.
  4. Restart the TV, wait for it to finish booting, then click Connect TV again.

Your launcher installation and Home settings are not erased; this only restores the remote-control SDB service.

What stays intact?

Launcher changes do not remove Netflix, YouTube, HDMI inputs, or installed TV apps. Home assignment changes are reversible using Restore Samsung Launcher.
