# Security Policy

## Reporting a vulnerability

Please do not publish exploitable details, credentials, private certificates, or TV access information in a public issue.

Until a private security contact is configured for this repository, open a minimal issue titled `Security contact request` without including sensitive details. The maintainer will provide a private reporting channel.

## Sensitive information

Before sharing logs or screenshots, remove:

- TV IP addresses and MAC addresses
- Developer Mode credentials or tokens
- Private keys, certificates, and signing files
- Personal usernames and local file paths
- Network names and other identifying information

CleanFrame Manager should only be used against televisions that the user owns or is authorized to administer.
